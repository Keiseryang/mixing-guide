P01 线材

线材的认识与管理收纳

先分清哪根线干嘛，再学会别让线打结绊倒人。

1认识常见线材

现场最常用的就这几种，记住它们的外形和用途即可。

🎙️

XLR 卡侬线

抗干扰的「平衡线」，麦克风/主输出常用。分公头（3针）与母头（3孔）。

🔩

TRS 大三芯

6.35mm 三圈「平衡线」，插头为公头。乐器、监听、输出常用。

🎸

TS 大二芯

6.35mm 两圈「非平衡线」，电吉他/键盘等短线用。

🔊

功放线（电源线+信号线）

功放供电用电源线，声音到音箱用信号线（图：带锁扣的 Speakon 线）。

2怎么看「公头 & 母头」（重要！）

凸出=公头、凹陷=母头；输出端用公头、输入端用母头，避免带电针脚碰金属。

凸=公、凹=母，公去插、母被插。一根 XLR 线一头公、一头母。
💡
一句话分：三根/三圈=平衡（抗干扰、长线）；两圈=非平衡（短线、家用）。现场尽量用平衡线。

3怎么管理线材：理线 & 绕线

⊕ 绕线手法（正反绕 / 8 字绕法）

正反交叉着绕，线不自动打结，一拉就开。别硬拽、留余量、接头处别勒死。

⊕ 上电前 \ 收工后

  • 接线前摆顺线、两头贴标签编号。
  • 横穿走道用扎带 / 盖线槽固定，防绊倒。
  • 收工按编号收回，别随手一丢。
⚠️
安全提醒散线=绊倒隐患。横穿走道要贴地固定，接头保持干燥清洁。
P02 麦克风

麦克风的认识与 48V 幻象电源

先分清动圈 / 电容，再记住谁要 48V，别把设备烧了。

1两种常用麦克风

🎤

动圈麦

结实抗干扰，现场人声首选。经典如 SM58。不需要供电。

✨

电容麦

细腻灵敏，分小振膜（乐器）和大振膜（人声）。需要 48V 供电。

2一句话记住 48V

🔑
只有电容麦克风和主动 DI 盒需要幻象供电；其它自己有电的设备千万别开，会烧掉，烧了要赔钱。

3DI 盒（乐器进调音台）

把吉他/贝斯转成平衡信号，长距离不衰减。

🔌

J48（有源）

需 48V 或电池供电。

🪶

JDI（无源）

不需供电，纯变压器。

4人声麦克风的选择

常见经典，选对少走弯路。

型号类型适合
Shure SM58动圈现场主唱首选，抗干扰、不易啸叫
Shure SM57动圈人声/乐器都行，声音比 58 更亮更贴
Shure Beta 181C电容小振膜，主打乐器/弦乐，细节好
Sennheiser E935动圈现场人声，声音前突有力不费劲
Shure KSM9电容录音/抒情人声，细腻，需 48V
P03 接线实战

现场接线实战

看懂这一场：Avantis 在 FOH，GX4816 在舞台侧面，两根 12 路多芯缆接进接口箱 1–24 路。

🎛️

Avantis

调音台 · FOH 位置，负责调音。

📦

GX4816

接口箱 · 舞台侧面，48 入 16 出。

🧬

12 路多芯缆

两根（舞台左侧 / 中前），接进接口箱 1–24 路。

🔀
信号流：舞台乐器/麦克风 → 12 路多芯缆 → GX4816 输入 1–24 → 数字链路 → Avantis 通道 →调 GAIN。本模块重点在这一环节。

1谁用麦克风拾音，谁直接乐器线输出

🎤 用麦克风拾音（声学/需扩声）

  • 人声（主唱 / 和声）
  • 鼓组：底鼓、军鼓、通鼓、镲片
  • 原声吉他 / 木吉他
  • 铜管、木管、弦乐、手风琴等
  • 电吉他音箱（用麦对着喇叭拾音）

🔌 直接用乐器线（电声/有输出）

  • 电吉他 / 贝斯（高阻输出）
  • 键盘、合成器（线路输出）
  • 电箱琴（带拾音器，直接接）
  • 采样器、音源等电子乐器
  • 需要 DI 或高阻通道（见下）

2① 怎么把麦克风接入调音台

第 1 步 · 选好要用的麦克风

先确定用动圈 / 电容哪种，确认接口、线材，以及要不要 48V。

第 2 步 · 找到要用的通道，先处理干净再接入

① 在调音台里先找到要用的那个通道 → ② Mute 掉并把推子拉到底部 → ③ 再修改输入来源（把该通道对应到要用的轨道）→ ④ 再看 48V 与 Gain（电容麦开 48V、动圈不开，GAIN 从 0 开始）→ ⑤ 确认无误后再把麦克风或其他乐器通过线材接入到接口。

第 3 步 · 直接看该轨道的输入电平来判断合不合适

接好后用正常声音说话，看该轨道的输入电平表（PFL / 表头）——过大降 GAIN、过小升 GAIN；不要用主输出音量来试。

3② 怎么把键盘接入（两种方式）

方式一 · DI 盒

键盘 → DI → 卡侬 → 多芯缆 → 接口箱。声音更稳、可长距离。

  • J48：有源，要开 48V
  • JDI：无源，不用 48V

方式二 · 大三芯转卡农线

键盘(TRS out) → TRS 转 XLR → 多芯缆 → 接口箱。

  • 线路信号，不用供电
  • 若键盘输出非平衡，长线易受干扰

4③ 简单排查（分话筒 / 乐器·DI 盒两版）

没声音时，从调音台往回推演信号链路，先查靠台子这端，一路查到信号源。按你的接入方式选下面一版。

🎤 话筒版

现象先查（从台子往回）
完全没声音① 增益是否 OK（GAIN 看电平）→ ② 输入来源（通道号选对没）→ ③ 线材 → ④ 麦克风本体
嗡嗡底噪是否误开 48V、切换下接地开关看是否消除

🎹 乐器（DI 盒）版

现象先查（从台子往回）
完全没声音① 增益是否 OK → ② 输入来源 → ③ 线材 → ④ DI 盒 → ⑤ 线材 → ⑥ 乐器本体（键盘/吉他）
嗡嗡底噪是否误开 48V（有源 DI 才开）、切换下接地开关看是否消除
P04 现场乐队设置

现场乐队设置指南

开演前一站式把设备 / 通道 / 返听都整理好，乐队上台就能直接开声，不慌乱。

1乐队到达前，备好全部设备

在乐队到达之前，把整场会用到的所有东西提前备齐、检查好：

  • 线材：卡侬（XLR）、大三芯、吉他线
  • 话筒：人声、鼓组、乐器按数量配足
  • 设备：DI 盒、接口箱 / 舞台侧设备、返听音箱
  • 提前思考下舞台输入安排，尽量让线绕开乐队行走区域，维持舞台美观

2调音台先把通道设置完毕

在调音台上把所有要用的通道先设置完：逐个确认通过、把通道配置到正确轨道，然后全部 Mute。这一步让台面先“就绪”，等乐队上台只需接线。

3上台前接线，逐个测试

假如用的都是场地的设备，就在乐队上台前先把设备按规划接好，再逐个通道测试——确认每一路都有声、电平合适，有问题当场解决。

4人声提前送到歌手返听

提前给歌手发送一些返听（只要清晰即可，不用大声），让歌手一上台就能听清自己的声音。

🎧
提醒：返听（Monitor）的声音通常使用推子前（Pre-fader）发送给返听音箱——这样返听音量不受主推子（Fader）位置影响，伴奏与人声都能稳定送达。
